## Current engineering workflow

1. Define architecture, constraints, and acceptance criteria.
2. Let a high-capability agent explore the codebase and plan the work.
3. Delegate bounded implementation tasks to a coding agent such as Codex.
4. Review diffs, runtime behavior, and integration against the real system.
5. Feed concrete failures back into the workflow instead of blindly reprompting.
6. Turn recurring solutions into reusable tools, skills, configuration, or documentation.

I am especially interested in the engineering around agents: **context, boundaries, tools, observability, fallback behavior, validation, and recovery**.
